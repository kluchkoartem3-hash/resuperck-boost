# Resuperck Boost — сайт проекта

Статический сайт бесплатного Windows-приложения Resuperck Boost 1.4.0: возможности, демонстрационные скриншоты, помощь, связь с автором и добровольная поддержка.

Для публикации GitHub Pages выберите Settings → Pages → Deploy from a branch → основная ветка → /(root). Файл index.html расположен в корне; сборка и установка зависимостей для сайта не требуются. .nojekyll отключает обработку Jekyll.

Готовый установщик и публичный архив исходников размещаются отдельно в Releases v1.4.0, а не в Git-истории сайта. Ссылки страницы и releaseUrl в site-config.js настроены на соответствующие release assets; эти файлы должны существовать в опубликованном релизе.

Для локального просмотра из этой папки при наличии Python: `py -3 -m http.server 8000 --bind 127.0.0.1`, затем откройте http://127.0.0.1:8000/.

## Связь и настройки

Публичные адреса, версия и ссылка загрузки задаются в site-config.js. contactEndpoint пока равен null: форма сообщения скрыта, работает личная связь через Telegram. Адаптер отправки формы сохранён для будущего подключения проверенного маршрута или сервиса; сайт сам по себе письма не отправляет. На сайте нет платёжной формы и аналитики. Банковские секреты, пароли, токены и приватные ключи в файлы сайта добавлять нельзя.

Страница использует локальные изображения и системные шрифты. Скриншоты показывают интерфейс программы и могут содержать демонстрационные данные. Выбор темы хранится в браузере посетителя.

Самостоятельная лицензия сайта в исходных материалах не была указана; этот репозиторий не добавляет новых лицензионных разрешений. Лицензии программы и её зависимостей находятся в отдельном архиве исходников приложения. Автор проекта и бренда — Resuperck.
