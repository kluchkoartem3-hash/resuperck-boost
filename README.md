![Resuperck Tools hardware overview](assets/screenshots/overview.png)

Resuperck Tools is the new name of Resuperck Boost. Version 1.5.0 adds management of supported startup entries and selective removal of packaged Windows apps for the current user. Recorded startup entries can be restored; protected dependencies are excluded from app removal. App-data backup is not included, and reinstallation depends on package availability.

The application also includes per-game profiles, DLSS/NR graphics tools, optional SCSKiller shader preparation, NVIDIA controls, an app assistant and external Melty launcher support. Cloud answers use a shared free quota; offline help remains available. The assistant cannot operate the PC. Games and ready-made mods are selected in Melty’s catalogue; arbitrary co-op generation is not included.

The screenshot uses demonstration data. Graphics features depend on the game and hardware; use the game's built-in settings when anti-cheat restrictions apply.

This repository contains the website. The application code, build instructions and dependency licences are included in the source archive linked above.
