# Resuperck Boost

[Русский](README-RU.md)

A free app for Windows 10 / 11 x64 that brings PC hardware information, Windows settings, game profiles and graphics tools into one interface.

Version 1.4.1 adds an app assistant, external Melty launcher support and installation/removal of the Deus Ex GOTY co-op beta. The cloud assistant needs no model download and uses a shared free quota; offline help remains available. It cannot operate the PC. Melty uses its own catalogue; this is not a universal tool for generating co-op or combining arbitrary games.

The screenshot uses demonstration data. Graphics features depend on the game and hardware; use the game's built-in settings when anti-cheat restrictions apply.

The co-op installation and restoration were checked on test folders; in-game compatibility has not been tested. This repository contains the website. The application code, build instructions and dependency licences are included in the source archive linked above.
